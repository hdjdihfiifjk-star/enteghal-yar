# انتقال‌یار — Local Wi‑Fi / QR

## هدف
فقط گوشی اول برنامه را نصب می‌کند. گوشی دوم هیچ APK ندارد؛ QR را اسکن می‌کند و مرورگر گوشی دوم صفحه وب را مستقیماً از گوشی اول دریافت می‌کند.

## جریان کار
1. روی گوشی اول APK را نصب کنید.
2. گوشی اول و دوم را روی یک Wi‑Fi قرار دهید؛ یا در صورت پشتیبانی دستگاه، Hotspot گوشی اول را دستی روشن کنید و گوشی دوم را به آن وصل کنید.
3. انتقال‌یار را روی گوشی اول اجرا کنید.
4. QR نمایش داده می‌شود.
5. گوشی دوم QR را با دوربین اسکن کند.
6. مرورگر گوشی دوم آدرس `http://<IP>:8080/join` را باز می‌کند.
7. صفحه وب از خود گوشی اول سرو می‌شود.
8. انتخاب فایل در گوشی دوم باعث ارسال مستقیم HTTP روی LAN به گوشی اول می‌شود.

## اینترنت
برای انتقال فایل اینترنت لازم نیست. ترافیک فایل روی شبکه محلی است.

## نکته Android
مرورگر و Web App خالص اجازه ساخت HTTP server روی گوشی را نمی‌دهند؛ بنابراین تنها لایه Native این نسخه «Local Web Server» است و UI و تجربه کاربر وب‌اپلیکیشن باقی می‌ماند.

## ساخت APK
در GitHub، Workflow زیر را اجرا کنید:
Actions → Build Android APK → Run workflow
سپس Artifact `EnteghalYar-localwifi-apk` را دانلود کنید.
